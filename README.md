# python-practice

Автор: Руслан Чухно, група МІТ-1026а.

Практична робота П3 — функції та Git. Виконано всі три рівні й додаткові вправи.

## Файли

- level1.py — задачі 1–5: температура, площа, мінімум і максимум, прості числа, рамка.
- level2.py — задачі 6–8: факторіал, Фібоначчі, НСД, НСК, дроби й цифри числа.
- mathtools_project/mathtools.py — бібліотека математичних функцій з docstrings.
- mathtools_project/main.py — меню, імпорт бібліотеки та введення/виведення.
- report.md — блок-схеми, трасування, тести, порівняння швидкості й Git-звіт.
- .gitignore — службові папки, які не відстежуються.

## Запуск

Потрібен Python 3, сторонні бібліотеки не потрібні. У терміналі папки проєкту:

```text
python level1.py
python level2.py
python mathtools_project/main.py
```

Меню: 1 — НСД і НСК; 2 — просте число; 3 — факторіал; 4 — ділення;
5 — степінь; 0 — вихід. Числа вводьте по одному, десятковий роздільник — крапка.

Рівні 1 і 2 показують приклади під if __name__ == "__main__".
Під час імпорту модулів приклади та меню не запускаються.
Для рекурсивних алгоритмів використовуйте помірні аргументи;
fib_rec призначена для демонстрації, а не великих n.
